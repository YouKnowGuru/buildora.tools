## 拆除工程费用估算器

估算拆一栋住宅、车库、厂房、游泳池，或者只做室内打拆要花多少钱。输入结构类型、建筑面积、层数和拆除方式，工具会把人工费、渣土外运和报批费分项列出，公制英制一键切换。

**关于取值口径的重要提示。** 工具的单价、渣土产出系数和外运费都来自美国市场均值和北美监管流程：市政 demolition permit、EPA NESHAP 石棉检测、30 立方码（约 23 立方米）滚卸式垃圾箱。它没有按国内任何一本定额或清单规范标定，也不反映建筑垃圾处置核准的流程。把结果当量级参考，正式计价请套本省定额并按 GB 50500《建设工程工程量清单计价规范》组价。

## 计算流程

```
1. 选结构类型
2. 建筑面积（m2 或 ft2）
3. 层数（渣土量随层数线性增长）
4. 拆除方式系数：机械 1.00 | 静力/选择性 1.40 | 人工 1.65
5. 人工费   = 建筑面积 x 单价 x 方式系数
6. 渣土量   = 建筑面积 x 渣土系数 x 层数
7. 车次     = 渣土量 / 23 m3（30 立方码箱）
8. 外运费   = 车次 x 550 美元（均值）
9. 总费用   = 人工费 + 外运费 + 报批费
```

**机械拆除**用挖机加破碎锤、液压钳或抓斗，绝大多数情况最省钱，因为把工日换成了台班。**人工拆除**在城区窄场地、贴邻墙体和机械进不去的部位无法回避。**静力（选择性）拆除**贵四成左右，但用绳锯、水钻和液压钳可控，噪声粉尘小，贴邻既有建筑或需要保留主体时基本只能这么干，同时能提高钢材、木料和构件的回收率。

## 国内怎么计量、怎么办手续

**一、清单不按建筑面积包干，按构件分项。** GB 50854《房屋建筑与装饰工程工程量计算规范》把拆除工程拆成一长串子目，各自的计量单位不同：

| 清单子目 | 计量单位 |
|---|---|
| 砌体拆除、混凝土及钢筋混凝土构件拆除 | m³（部分按 m²） |
| 抹灰层铲除、块料面层拆除、屋面拆除 | m² |
| 龙骨及饰面拆除、轻质隔墙拆除 | m² |
| 门窗拆除 | m² 或樘 |
| 金属构件拆除 | t |
| 管道拆除、栏杆栏板拆除 | m |
| 卫生洁具、灯具拆除 | 套 / 个 |

各省定额里的房屋整体拆除子目多按建筑面积或外围体积计量，具体规则看本省定额的工程量计算规则。工具输出的是"每平方米一个综合价"，和国内清单口径对不上，需要自己拆分。

**二、没有"拆除许可证"这个东西。** 施工性质的拆除要由具备资质的施工单位承担，编制专项施工方案；拆除工程列入危险性较大的分部分项工程范围，可能影响行人、交通、管线或邻近建构筑物时必须编专项方案并履行审批，超过一定规模的还要组织专家论证。此外要按《城市建筑垃圾管理规定》办理建筑垃圾处置核准，运输车辆须密闭并持有准运手续。征收拆迁走的是《国有土地上房屋征收与补偿条例》，与施工拆除是两条完全不同的线。

**三、石棉按危险废物管。** 国内不适用 EPA NESHAP，但废石棉列入《国家危险废物名录》（HW36），老厂房和农村建筑常见的石棉水泥瓦必须交有危险废物经营许可证的单位处置，转移执行危险废物转移联单制度。这部分费用工具完全不含，且往往要先做完才能开拆。

## 常见问题

### 拆一栋 140 平方米的房子要多少钱？

按工具的美国参数，139 平方米（1500 平方英尺）轻型木框架住宅人工费约 8000 到 16000 美元，加渣土外运 2000 到 4000 美元、报批 300 到 800 美元，合计 10000 到 20000 美元。同体量砌体结构再上浮 50% 到 80%。国内同类项目建议按分部分项重算：混凝土构件拆除的机械和外运占比明显更高。

### 哪种拆除方式最便宜？

机械拆除。同样面积，人工拆除的人工费要高出 60% 到 80%。静力拆除居中，能靠材料回收找回一部分成本，且在噪声、粉尘和振动受限的场地是唯一可行方案。

### 拆房子要办什么手续？

工具对应的美国流程是市政拆除许可，200 到 1000 多美元，商业和工业建筑还要先做石棉检测。国内不是一纸许可，而是资质单位承担、专项施工方案、危大工程审批（必要时专家论证）、建筑垃圾处置核准、渣土运输准运一整套。涉及历史建筑或文保单位另有报批程序，开工前务必与主管部门和监理确认。

### 拆一栋楼要多久？

139 到 186 平方米的轻型结构机械拆除 1 到 3 天。砌体或钢筋混凝土结构用液压钳加现场破碎，按 1 到 2 周考虑；静力拆除可能到三周。这些工期后面还要加渣土清运时间，在城区受限行和消纳场排队影响，往往才是真正的瓶颈。

### 只做室内打拆多少钱？

拆隔墙、地面、吊顶、水电和洁具，主体不动，工具给的是每平方米 22 到 43 美元（每平方英尺 2 到 4 美元）。这是全表里人工占比最高的子目，因为按定义就是手工作业。国内二手房打拆通常按建筑面积或按构件分项报价，还要计入垂直运输（有无电梯差别很大）和物业规定的作业时段。
