## 应急备用电源与储能电池容量计算器：逆变器选型与续航时间

本**备用电池与家庭储能系统计算器**能够帮助您精准计算停电断电期间维持关键用电设备运行所需的电池容量、逆变器输出功率以及太阳能光伏充电板规格。

计算器可输出：

- **关键负载连续运行总功率（W）**与全天耗电量（Wh 或 kWh）
- **推荐电池总容量**（以瓦时 Wh 和安时 Ah 表示）
- **推荐逆变器规格**（包含电机启动浪涌与安全冗余）
- **满载预计续航运行时间**
- **每日独立补电所需太阳能光伏功率（Wp）**
- **电池化学特性投资对比**（磷酸铁锂 LiFePO₄ 对比铅酸 / 胶体电池）

## 1. 备用电源系统核心构成

一套完整可靠的电池备电系统由四个相互配合的核心部件构成：

| 组成部分 | 系统功能 | 选型关键指标 |
|---|---|---|
| **电池组（储能系统）** | 以直流电（DC）形式储存电能 | 可用容量（Wh / Ah）与系统电压（12V、24V 或 48V） |
| **逆变器 / 充电一体机** | 将直流电转换为交流电（AC 220V/110V） | 额定持续输出功率与抗峰值冲击能力 |
| **光伏充电控制器** | 控制太阳能电池板平稳向电池充能 | 高转换效率的 MPPT 控制技术 |
| **自动转换开关（ATS）** | 市电断电时自动且无感切换至电池供电 | 切换响应时间小于 20 毫秒 |

## 2. 放电深度（DoD）与电池寿命

**放电深度（Depth of Discharge，DoD）**是指电池在不损伤电芯物理结构和不过度衰减循环寿命的前提下，单次放电所能释放的最大标称容量百分比。

```
实际可用能量 (Wh) = 标称总容量 (Wh) x (放电深度 DoD / 100)
```

| 电池类型 | 推荐放电深度（DoD） | 循环使用寿命 | 综合充放电效率 |
|---|---|---|---|
| **磷酸铁锂（LiFePO₄）** | 80% – 90% | 3,500 – 6,000 次（10–15年） | 95% – 98% |
| **三元锂（NMC）** | 80% | 1,500 – 2,500 次 | 92% – 95% |
| **阀控免维护铅酸（AGM）** | 50% | 400 – 600 次（2–4年） | 80% – 85% |
| **富液 / 胶体铅酸电池** | 50% | 300 – 500 次 | 75% – 82% |

> **经济效益分析：** **磷酸铁锂电池（LiFePO₄）**在相同标称容量下可释放出近两倍的有效电能，其循环寿命是传统铅酸电池的七到十倍。从长期度电成本（LCOS）来看，磷酸铁锂是最经济的储能方案。

## 3. 分步计算公式

```
1. 需求总电量 (Wh) = 连续运行功率 (W) x 目标续航时长 (h)

2. 电池组标称容量 (Wh) = 需求总电量 (Wh) / (逆变器效率 x 放电深度 DoD)

3. 安时容量 (Ah) = 电池组标称容量 (Wh) / 系统直流电压 (V)

4. 逆变器最小功率 (W) = 连续运行功率 (W) x 1.25

5. 光伏充能功率 (Wp) = 每日总耗电量 (Wh) / (峰值日照时数 x 0.77)
```

### 实例测算：家庭关键负荷应急供电 8 小时

- **维持运转设备：** 节能冰箱（120W）、光纤猫与无线路由器（50W）、LED照明与风扇（60W）、笔记本与手机充电（120W） = **350 W**
- **目标断电续航：** 8 小时
- **总耗电需求：** 350 W × 8 h = **2,800 Wh（2.8 度电 / kWh）**
- **采用磷酸铁锂（80% DoD）配合纯正弦波逆变器（效率92%）：**
  - 所需电池总容量：2,800 / (0.92 × 0.80) = **3,804 Wh（约 3.8 kWh）**
  - 选用 48V 直流母线：3,804 Wh / 48V = **79.25 Ah**（标准 48V 100Ah 储能锂电池模块）
  - 推荐逆变器规格：350 W × 1.25 = 437.5 W（实际选配额定功率不低于 1,000W 的纯正弦波逆变器，以承载冰箱压缩机瞬间启动电流）

## 4. 直流系统电压选择：12V、24V 还是 48V

| 系统直流电压 | 推荐持续负荷功率 | 直流线缆规格要求 | 典型适用场景 |
|---|---|---|---|
| **12 V** | 1,000 W 以下 | 极粗铜缆（大电流发热） | 房车、野营、游艇、小型直流监控 |
| **24 V** | 1,000 W 至 3,000 W | 中等线径 | 小型度假屋、农场小屋、中型离网设备 |
| **48 V** | 3,000 W 以上 | 较细且经济安全 | 独栋住宅全屋备电、大型户用光伏储能 |

将系统电压由 12V 提升至 48V 后，在同等输出功率下直流工作电流降低至四分之一，线路发热损耗大幅降低 94%，并显著减少铜缆投资。

## 常见问题解答

### 每天给电池充满电需要多少块太阳能板？
将每日耗电量（Wh）除以当地年均峰值日照时数（一般地区约为 3.5 到 4.8 小时），并乘以系统综合效率系数 77%。若每日消耗 3,800 Wh 电量，在 4.5 小时峰值日照条件下，大约需要配备 1,100 W 太阳能电池板，即三块 400W 单晶硅光伏组件。

### 为什么必须使用纯正弦波逆变器？
纯正弦波逆变器输出的交流电波形与国家公用电网完全一致。方波或修正正弦波逆变器会导致电机类设备（如冰箱压缩机、空调、水泵）异常发热、发出嗡嗡噪音，并可能直接击穿烧毁精密电子设备的开关电源。

### 冬季低温对电池储能表现有什么影响？
低温会导致电解液离子活性降低。普通铅酸电池在 0 °C 时的实际可用容量会下降 25% 至 30%。磷酸铁锂电池在低温下仍具备良好的放电能力，但内置的 BMS 电池管理系统在电芯温度低于 0 °C 时会切断充电输入，以避免在负极形成金属锂枝晶损坏电芯。
