## 软水机选型计算器：格林、毫克每升与国标口径

这个工具按**美国水质协会（WQA）和 NSF/ANSI 44 的格林容量法**给离子交换软水机定型号：输入家庭人数、原水硬度（GPG 或 ppm）、溶解性铁和锰含量、期望再生周期，得到推荐格林容量（24K 到 96K 或商用双罐）、树脂体积（立方英尺）、罐体尺寸（英寸）、日去除硬度量、年耗盐量（磅和 40 磅袋数）、再生排水量（加仑）和峰值流量（GPM）。

**国内表达硬度和标定设备的方式都不一样。** 硬度用**总硬度，以 CaCO3 计，单位 mg/L**，或用 mmol/L，进口设备说明里还会见到德国度（°dH）；GB 5749-2022《生活饮用水卫生标准》规定总硬度限值为 **450 mg/L**。设备不按"多少 K 格林"标定，而是按**产水量 m³/h、树脂装填体积 L 和周期制水量 m³/周期**；工业和供热场景按 GB/T 1576《工业锅炉水质》控制给水硬度，建筑给水按 GB 50015《建筑给水排水设计标准》。另外国内销售涉及饮用水的水处理设备需要**涉水产品卫生许可批件**，这是行政许可，不是 NSF 那种自愿认证。

## 硬度单位换算

```
1 GPG（格林/加仑）  = 17.1 mg/L（以 CaCO3 计）
1 德国度 °dH        = 17.8 mg/L
1 mmol/L            = 100 mg/L
1 mg/L              = 0.0584 GPG
硬度(mol/m3)        = 总硬度(mg/L) / 100
1 美制加仑          = 3.785 升
1 立方英尺树脂      = 28.3 升
1 磅盐              = 0.454 千克
```

| 分级（常用口径） | 总硬度 mg/L（以 CaCO3 计） | 折合 GPG | 典型情况 |
|---|---|---|---|
| 极软水 | 0 到 75 | 0 到 4.4 | 部分南方山区地表水 |
| 软水 | 75 到 150 | 4.4 到 8.8 | 长江流域多数城市自来水 |
| 微硬水 | 150 到 300 | 8.8 到 17.5 | 华东、华中部分城市 |
| 硬水 | 300 到 450 | 17.5 到 26.3 | 华北、西北地下水源 |
| 极硬水 | 大于 450 | 大于 26.3 | 超出 GB 5749 限值 |

先查当地自来水公司公布的水质报告，那上面的总硬度是以 CaCO3 计的 mg/L，除以 17.1 就能换成工具需要的 GPG。南方城市多在 100 到 200 mg/L，装软水机的必要性不大；华北、西北和自备井取水常到 300 到 500 mg/L，才是真正需要软化的场景。

## 国标口径的选型流程

国内不用格林容量，用**树脂工作交换容量**（单位 mol/m³ 树脂，以二价离子计）。常用的 001 x 7 强酸性阳离子交换树脂工作交换容量在 **900 到 1100 mol/m³** 量级，具体取值随再生盐耗、流速和原水水质变化，按产品手册取。

```
1. 日用水量(m3/d)   = 人数 x 用水定额(L/人/d) / 1000
2. 原水硬度(mol/m3) = 总硬度(mg/L) / 100
3. 日去除量(mol/d)  = 日用水量 x 原水硬度
4. 需要交换量(mol)  = 日去除量 x 再生周期(d) x 安全系数(1.2)
5. 树脂体积(m3)     = 需要交换量 / 工作交换容量
6. 周期制水量(m3)   = 树脂体积 x 工作交换容量 / 原水硬度
7. 每次盐耗(kg)     = 树脂体积 x 盐耗(kg/m3)     （80 到 150 kg/m3）
8. 年耗盐(kg)       = 每次盐耗 x 365 / 再生周期
```

**用水定额差别很大。** 工具默认每人每天 75 美制加仑，即 **284 升**；国内住宅生活用水定额按 GB 50015 取 **130 到 300 升每人每天**，且计算软水量时通常只算洗浴、洗衣、厨房用水，不含绿化和景观。定额差一截，算出来的设备就差一档。

---

## 算例：四口之家，原水 300 mg/L

* 用水定额取 200 升每人每天：日用水量 = 4 乘 200 / 1000 = **0.8 立方米/天（211 美制加仑）**
* 原水硬度 = 300 / 100 = **3.0 mol/立方米（17.5 GPG）**
* 日去除量 = 0.8 乘 3.0 = **2.4 mol/天**
* 目标再生周期 5 天，安全系数 1.2：需要交换量 = 2.4 乘 5 乘 1.2 = **14.4 mol**
* 工作交换容量取 1000 mol/立方米：树脂体积 = 0.0144 立方米 = **14.4 升**，按产品档位取 **20 升**
* 周期制水量 = 0.02 乘 1000 / 3.0 = **6.7 立方米**，约 8 天再生一次
* 盐耗取 100 kg/立方米树脂：每次 **2.0 千克**，年耗盐约 **91 千克（201 磅）**
* 再生排水按树脂体积的 8 到 12 倍：每次约 **0.2 立方米（53 美制加仑）**，年约 9 立方米

同一家庭用工具算：4 人乘 75 加仑乘 17.5 GPG 乘 7 天乘 1.2 得约 44000 格林，推荐 48K 型号、1.5 立方英尺（42 升）树脂，年耗盐 250 磅（113 千克）以上。差距来自两处：**用水定额**（284 对 200 升）和**再生策略**（工具按 7 天周期加 20% 余量，国内更倾向 3 到 7 天短周期、树脂装填量小一档）。方向一致，量级差 1.5 到 2 倍。

## 铁和锰的折算

标准硬度检测只测钙镁，溶解性二价铁和锰同样占用树脂交换位，选型时必须折算进去：

```
折算硬度(GPG)   = 原水硬度 + 铁(ppm) x 4 + 锰(ppm) x 2
折算硬度(mg/L)  = 原水硬度 + 铁(mg/L) x 68 + 锰(mg/L) x 34
```

这条 WQA 规则在国内同样适用，但要分清水质类型：只有**溶解性亚铁**（水刚接出来清澈、放置后变黄）能靠离子交换带走；已经氧化成三价铁的**红水铁**是颗粒物，必须在软水机前设锰砂过滤器或曝气氧化装置，单纯加大软水机只会把树脂堵死。GB 5749 对铁的限值是 0.3 mg/L、锰 0.1 mg/L，自来水一般合格，自备井水超标很常见，接井水的项目要先做全项水质检测。

## 流量与管径

| 卫生间数量 | 峰值流量 | 建议接口 |
|---|---|---|
| 1 个 | 1.6 立方米/小时（7 GPM） | DN20（3/4 英寸） |
| 2 个 | 2.3 立方米/小时（10 GPM） | DN25（1 英寸） |
| 3 个 | 3.0 立方米/小时（13 GPM） | DN25（1 英寸） |
| 4 个 | 3.6 立方米/小时（16 GPM） | DN32（1-1/4 英寸） |
| 5 个及以上 | 4.3 立方米/小时以上 | DN32 以上大流量阀 |

换算关系：`1 GPM = 0.227 立方米/小时`。国内住宅入户管一般 DN20 或 DN25，中央软水机装在入户总阀后、分水器前，并必须设旁通管和检修阀，再生时或设备故障时能切换到原水，这一条在精装交付里经常被漏做。

## 常见问题

### 我家水到底硬不硬，怎么查？

看当地自来水公司每月公布的水质检测报告里的"总硬度（以 CaCO3 计）"，单位 mg/L。也可以买硬度试纸或滴定试剂自测，但注意试纸刻度可能是德国度或 GPG，换算按 1 °dH = 17.8 mg/L、1 GPG = 17.1 mg/L。判断门槛：低于 150 mg/L 一般不必软化，300 mg/L 以上花洒结垢、热水器结垢会明显加快，值得装。

### 美国说的"32K 软水机"相当于国内多少升树脂？

32000 格林对应约 1.0 立方英尺树脂，即 **28.3 升**；48K 约 42 升，64K 约 57 升，96K 约 85 升。反过来，国内常见的家用 20 升、25 升机型大致落在美制 22K 到 28K 这一档。注意格林容量是在特定盐耗下标定的，同一体积树脂按高盐耗再生能标出更大的格林数，跨体系比较时要看树脂体积而不是标称格林。

### 一年要用多少盐，用什么盐？

按上面公式算：树脂体积乘盐耗（80 到 150 kg/立方米）得每次用量，再乘一年的再生次数。20 升树脂、5 到 8 天一次周期，年耗盐 90 到 150 千克，即 4 到 7 袋 25 千克装。必须用软水机专用**颗粒盐或纯度 99% 以上的精制盐**，不能用加碘食盐、腌制盐或工业粗盐——杂质和抗结块剂会污染树脂、堵塞喷射器。

### 软化后的水能直接喝吗？

离子交换是用钠置换钙镁，出水钠含量会升高，硬度越高升幅越大。GB 5749 对钠没有单独限值，正常饮用没有安全问题，但限钠人群和婴幼儿冲奶不建议直接用。国内主流做法是分路供水：软水供洗浴、洗衣、地暖和热水器，厨房饮用水单独走反渗透净水器或保留一路原水。软水机不去除余氯、有机物、硝酸盐和微生物，不能替代净水器。

### 再生废水能直接排吗？

家用再生排水是高浓度氯化钠溶液，一般允许排入市政污水管网，但要接到地漏或专用排水口并留存气隔断，不能直排雨水管或绿地。商用和工业软化站排水量大得多，含盐废水排放要按当地环保要求核对。安装前先确认现场有排水条件，排水管高度和长度受设备背压限制。

### 工具算出的型号能直接照单买吗？

型号档位、罐体英寸尺寸和 40 磅袋数是美国产品口径，国内市场买不到对应规格。可以用的是它的逻辑链条：日用水量乘折算硬度得到日去除量，乘周期和余量得到需要的交换容量。把这条链条换成国标单位（立方米、mg/L、mol/m³、升树脂、千克盐）重算一遍，再对着国内产品的产水量和树脂体积选型，同时确认设备有涉水产品卫生许可批件。
