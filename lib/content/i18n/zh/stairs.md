## 楼梯计算器：踏步、梯段与国标限值

楼梯是住宅里最容易出事的构件，也是尺寸容错最小的构件。这个工具按**美国 IRC §R311.7（住宅）和 IBC §1011（公共建筑）**计算踏步高、踏步宽、斜梁长度、倾角、净高、扶手长度和栏杆立杆数量。

**国内不按这两本规范。** 民用建筑楼梯的几何限值执行 GB 50352《民用建筑设计统一标准》和现行强制性规范 GB 55031-2022《民用建筑通用规范》，住宅另有 GB 50096《住宅设计规范》，疏散楼梯还要满足 GB 50016《建筑设计防火规范》。数值和分类方式都与美标不同，下面逐项对照。更关键的是构造：国内住宅楼梯是现浇钢筋混凝土板式或梁式楼梯，配筋和构造查国标图集 16G101-2，工具输出的 2x12 木斜梁长度、throat depth（斜梁剩余净截面）这些参数在国内工程里没有对应物。

---

## 术语

| 术语 | 含义 |
|---|---|
| **层高（总高）** | 下层建筑面层到上层建筑面层的垂直距离，唯一必须现场实测的数据 |
| **踏步高（踢面）** | 每级台阶的垂直高度，国内也叫踢面高 |
| **踏步宽（踏面）** | 脚踩的水平尺寸，不含突缘重叠部分 |
| **突缘（鼻子）** | 踏面挑出踢面的部分，一般 20 到 30 毫米 |
| **梯段水平投影长** | 一跑楼梯的水平总长，等于踏步数乘踏步宽 |
| **梯段净高** | 踏步前缘线到上方障碍物的垂直距离 |
| **倾角** | 梯段斜线与水平面的夹角，舒适区 30° 到 37° |
| **布隆代尔公式** | 2 乘踏步高加踏步宽，落在 600 到 635 毫米最省力 |

---

## 计算流程

```
1. 级数     = 四舍五入(层高 / 目标踏步高)
2. 踏步高   = 层高 / 级数        （同一梯段必须完全一致）
3. 踏步数   = 级数 - 1           （上层楼面充当最后一个踏面）
4. 投影长   = 踏步数 x 踏步宽
5. 斜长     = 根号(层高平方 + 投影长平方)
6. 倾角     = 反正切(踏步高 / 踏步宽)
7. 舒适校核  600 <= 2 x 踏步高 + 踏步宽 <= 635  (mm)
```

## 踏步限值：国标与美标对照

| 依据 | 踏步高上限 | 踏步宽下限 | 适用 |
|---|---|---|---|
| **GB 50352 住宅公共楼梯** | 175 毫米（6.9 英寸） | 260 毫米（10.2 英寸） | 单元楼梯、楼梯间 |
| **GB 50352 住宅套内楼梯** | 200 毫米（7.9 英寸） | 220 毫米（8.7 英寸） | 跃层、别墅内部楼梯 |
| **GB 50352 其他民用建筑** | 170 毫米（6.7 英寸） | 260 毫米（10.2 英寸） | 办公、商业、旅馆 |
| **GB 50352 小学宿舍** | 150 毫米（5.9 英寸） | 260 毫米（10.2 英寸） | 中小学、幼儿园从严 |
| IRC §R311.7（美国住宅） | 197 毫米（7.75 英寸） | 254 毫米（10.0 英寸） | 独栋、联排、公寓 |
| IBC §1011.5（美国公建） | 178 毫米（7.0 英寸） | 279 毫米（11.0 英寸） | 办公、零售、学校 |

读法：国标住宅公共楼梯（175/260）比 IRC（197/254）更平缓，接近 IBC 的严格程度；而国标允许住宅套内楼梯做到 200/220，比 IRC 还陡。也就是说，同一栋楼里楼梯间和入户内楼梯适用两套不同限值，工具只有"住宅"和"商业"两档，套不进来。

有意思的是两套体系的舒适性判断是一致的：国标限值 175/260 代入布隆代尔公式得 610 毫米，套内限值 200/220 得 620 毫米，都落在 600 到 635 毫米的舒适区内。

**另外几条国标硬性要求：**每个梯段的踏步数不应超过 18 级、不应少于 3 级；梯段净高不应小于 2.20 米，平台处及其上下过道净高不应小于 2.00 米（IRC 的 80 英寸即 2.03 米，比国标梯段要求低）；楼梯平台净宽不应小于梯段净宽，且不得小于 1.20 米；住宅楼梯梯段净宽不应小于 1.10 米，六层及以下且一边设栏杆时不应小于 1.00 米。

## 算例：层高 2900 毫米，住宅双跑楼梯

* 目标踏步高 165 毫米：2900 / 165 = 17.6，取 **18 级**（双跑等分，每跑 9 级）
* 实际踏步高：2900 / 18 = **161.1 毫米（6.34 英寸）**，小于 175 毫米，合规
* 踏步宽取 **280 毫米（11.0 英寸）**
* 每跑投影长：(9 - 1) x 280 = **2240 毫米**
* 每跑高度：9 x 161.1 = 1450 毫米；斜长 = 根号(1450² + 2240²) = **2668 毫米**
* 倾角：反正切(161.1 / 280) = **29.9°**，平缓舒适
* 布隆代尔校核：2 x 161.1 + 280 = **602 毫米**，合格
* 楼梯间开间校核：梯段净宽 1.15 米 x 2 + 梯井 0.15 米 = 2.45 米，需要 2.60 米以上开间

同一层高按 IRC 算会得到 14 级、每级 191 毫米——比国标住宅公共楼梯的上限还高，在国内直接不合规。这不是精度问题，是限值不同。

## 倾角与舒适性

| 倾角 | 评价 | 用途 |
|---|---|---|
| 小于 25° | 极平缓，接近坡道 | 无障碍坡道、大台阶 |
| 25° 到 30° | 平缓 | 公共建筑主楼梯、住宅楼梯间 |
| 30° 到 37° | 最舒适 | 常规住宅与公建楼梯 |
| 37° 到 42° | 偏陡 | 套内楼梯、地下室、检修楼梯 |
| 大于 42° | 陡 | 阁楼、爬梯，国内一般不作为主要通行楼梯 |

## 栏杆与扶手

国标要求比美标更细，也更严：

* 楼梯扶手高度自踏步前缘线量起不应小于 0.90 米；靠楼梯井一侧水平扶手长度超过 0.50 米时，其高度不应小于 1.05 米。
* 临空高度 24 米以下的栏杆高度不应低于 1.05 米，24 米及以上不应低于 1.10 米，从可踏部位顶面起算。
* 住宅、幼儿园、中小学等有儿童活动的场所，栏杆垂直杆件净距不应大于 0.11 米（IRC 用 4 英寸即 0.102 米球体判定，两者思路相同但数值不同）；不宜设置易攀登的水平构件。
* 住宅楼梯井净宽较大时必须采取防止儿童攀滑的措施。

立杆数量估算与工具一致：`每踏步立杆数 = 向上取整(踏步宽 / 立杆最大净距)`，再乘踏步数。按 110 毫米净距、280 毫米踏面算，每踏步 3 根。

## 常见问题

### 层高 2900 毫米要做多少级？

按住宅公共楼梯限值，踏步高不超过 175 毫米，2900 / 175 = 16.6，所以至少 17 级；双跑楼梯为了两跑等分通常取 18 级，每级 161 毫米。级数只能是整数，且同一梯段各级高度必须一致，误差控制在毫米级——踏步高不一致是国内验收和摔伤事故最集中的问题。

### 楼梯净高从哪里量到哪里？

从踏步前缘线沿垂直方向量到上方最近的障碍物：梯段处量到上一跑梯板底或梁底，取不小于 2.20 米；平台及其上下过道处量到板底或梁底，取不小于 2.00 米。注意量的是结构底面加装饰面之后的净空，不是抹灰前的尺寸。地下室楼梯和跃层内楼梯最容易在梯梁位置卡住这一条。

### 工具算出的斜梁长度和木料规格能用吗？

不能直接用。它算的是美式锯齿形木斜梁的斜长和 2x12 规格材，国内住宅楼梯是现浇钢筋混凝土板式或梁式楼梯，控制参数是梯板厚度、配筋和支座构造，做法查 16G101-2 等国标图集。斜长这个几何量本身是通用的，可以用来核对钢楼梯、木楼梯的下料长度，或者估算栏杆和扶手的长度。

### 室外台阶和楼梯一样算吗？

不一样。室外台阶踏步宽通常做到 300 毫米以上、踏步高 100 到 150 毫米，比室内平缓；台阶数少于 3 级时按坡道或单踏步另行处理，且要考虑防滑和排水找坡。工具没有室外台阶这一档。

### 扶手要多长，怎么算量？

按斜长加两端水平延伸段估算，工具给的是斜长加 300 毫米（12 英寸）。国内一般还要加平台段的水平扶手长度，双跑楼梯每层要加一段平台扶手，按实际展开长度计量。清单计价时扶手、栏杆按延长米（m）计量，与楼梯装饰面层按平方米计量分开列项。
