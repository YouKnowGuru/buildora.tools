## 外墙板与外墙饰面用量计算器

这个工具按**北美挂板（siding）工程的口径**算量：输入建筑长宽、檐口高度、山墙形式、门窗洞口，得到毛墙面面积、扣洞后的净面积、加损耗后的订货量，并换算成 **square（1 square = 100 平方英尺 = 9.29 平方米）**、纸箱数、起始条和阴阳角收边条的延长英尺数。材料库是乙烯基挂板、纤维水泥板（James Hardie）、工程木挂板（LP SmartSide）、雪松板和金属板。

**国内外墙不是这么做的，也不是这么算的。** 国内住宅是剪力墙或框架结构加加气混凝土砌块填充墙，外墙做法主流是**外墙涂料、真石漆、外墙面砖、干挂石材、保温装饰一体板和铝板或玻璃幕墙**，没有美式的木龙骨加 OSB 覆面板加防水透汽膜再挂板这套构造。计量按 **GB 50854《房屋建筑与装饰工程工程量计算规范》**，单位是平方米，扣减规则和美制完全不同；报价还要单列外脚手架等措施项目。工具的 square、纸箱数、J 型收边条这些输出在国内清单里没有对应子目，能用的是它的几何算量逻辑。

## 单位与计量口径对照

| 项目 | 美制 / 工具 | 国内做法 |
|---|---|---|
| 面积单位 | 平方英尺、square（100 平方英尺） | 平方米 |
| 洞口扣减门槛 | 大于 10 平方英尺（约 0.93 平方米）才扣 | **单个面积大于 0.3 平方米**的洞口就要扣 |
| 洞口侧壁 | 不计 | 抹灰不增加；块料按镶贴展开面积并入 |
| 附墙柱、梁、垛 | 含在墙面里 | 侧壁展开面积并入相应墙面 |
| 脚手架 | 通常含在人工报价内 | 措施项目单列，按外墙外边线长乘檐口高度以平方米计 |
| 山墙 | 三角形、复折式、拱形分别有公式 | 多为平屋面，改算**女儿墙**内外侧面积 |
| 材料包装 | 纸箱（2 square）、捆 | 按平方米、桶（涂料）、块（面砖、石材） |

0.3 平方米这条门槛值得记住：一扇 600 x 600 毫米的小窗在国内要扣，在工具里不扣。一栋楼几十个小洞口累计下来能差好几十平方米。

## 算量流程

```
1. 毛面积(m2)   = 外墙外边线周长 x 檐口高度（或各层层高之和）
2. 周长(m)      = 2 x (建筑长 + 建筑宽)
3. 扣减(m2)     = 单个面积大于 0.3 平方米的门窗洞口面积之和
4. 增加(m2)     = 女儿墙内外侧 + 附墙柱梁垛侧壁 + 块料洞口侧壁展开
5. 净面积(m2)   = 毛面积 - 扣减 + 增加
6. 订货量(m2)   = 净面积 x (1 + 损耗率)
7. 外脚手架(m2) = 外墙外边线长度 x 檐口高度      （措施项目）
```

**算例：**一栋 12.2 米 x 9.1 米（40 x 30 英尺）的三层住宅，檐口高 9.9 米，女儿墙高 1.2 米

* 周长 = 2 乘 (12.2 + 9.1) = **42.6 米（140 英尺）**
* 毛面积 = 42.6 乘 9.9 = **421.7 平方米（4539 平方英尺）**
* 门窗：24 扇窗每扇 1.8 平方米，1 扇门 2.1 平方米，合计扣 **45.3 平方米**
* 女儿墙内侧：42.6 乘 1.2 = **51.1 平方米**（外侧已含在檐高内）
* 净面积 = 421.7 − 45.3 + 51.1 = **427.5 平方米（4601 平方英尺）**
* 真石漆按 8% 损耗：427.5 乘 1.08 = **461.7 平方米**，按 3.5 kg/平方米 计约 **1616 千克**
* 外脚手架：42.6 乘 9.9 = **421.7 平方米**，单列措施费
* 折合美制约 **46 个 square**，可以用来和工具的输出互相校核

## 各种外墙做法的损耗与材料量

| 外墙做法 | 建议损耗 | 材料量指标（量级参考） | 常见部位 |
|---|---|---|---|
| 外墙弹性涂料、氟碳漆 | 3% 到 5% | 底涂 0.15 到 0.25、面涂两遍 0.3 到 0.5 kg/平方米 | 多层及高层住宅主流 |
| 真石漆、多彩仿石漆 | 5% 到 8% | 3 到 5 kg/平方米 | 仿石效果面层 |
| 外墙面砖（湿贴） | 3% 到 5% | 粘结砂浆 6 到 10 kg/平方米，另计勾缝 | 多层、裙房、旧改 |
| 干挂石材 | 5% 到 10% | 25 到 30 毫米厚板加龙骨挂件 | 公建、住宅裙房 |
| 保温装饰一体板 | 5% 到 8% | 按板规格排版，另计锚栓 | 节能改造、装配式 |
| 铝单板、蜂窝板幕墙 | 8% 到 12% | 2.5 或 3.0 毫米铝板加钢副框 | 公建立面 |
| 纤维水泥挂板、PVC 挂板 | 8% 到 12% | 按板规格 | 别墅、木结构、轻钢房 |

排版损耗和裁切损耗要分开看：涂料只有稀释和飞溅损耗，所以系数低；板材和石材是按规格排版下料，异形立面、弧墙、密集线条一上来，损耗直接翻倍。工具给的 5% 到 20% 区间方向是对的，但它按材料柔韧性分档，国内更多按**立面复杂程度和排版方式**分档。

## 国内特有的几条硬约束

1. **饰面砖脱落是重点管控项。** JGJ 126《外墙饰面砖工程施工及验收规程》要求做粘结强度拉拔检验，同类基层每 1000 平方米取一组，合格指标为平均值不小于 0.4 MPa。多个城市另有地方规定限制高层建筑外墙大面积使用饰面砖，方案阶段必须先查当地规定。
2. **外保温与饰面的防火分级。** GB 50016《建筑设计防火规范》按建筑高度限定外保温材料燃烧性能等级，并要求设置防火隔离带。外墙做法要和保温层一起报审，不能只看饰面材料。
3. **后置埋件和锚栓要验算。** 干挂石材、幕墙骨架、一体板锚栓打在混凝土或砌体上，属后锚固，须按 JGJ 145《混凝土结构后锚固技术规程》选型并做现场拉拔试验。砌体墙上直接干挂石材是不允许的。
4. **脚手架和垂直运输另计。** 国内清单计价里外墙装饰的措施项目（外脚手架、安全网、垂直运输、成品保护）单独列项，占比不低。只报一个"平方米综合单价"往往漏掉这一块。

## 常见问题

### 一个 square 是多少平方米？

1 square 等于 100 平方英尺，即 **9.29 平方米**；反过来 1 平方米约 0.108 square。看到进口挂板报价按 square 时，把它除以 9.29 换成元每平方米再和国内做法比。乙烯基挂板一箱通常是 2 square，即 18.6 平方米。

### 门窗洞口到底扣不扣？

国内按 GB 50854，**单个面积大于 0.3 平方米**的门窗洞口和孔洞要扣，小于这个面积的不扣。抹灰工程洞口侧壁和顶面不另增加面积；块料面层如果侧壁也要镶贴，按展开面积并入。工具的门槛是 10 平方英尺（0.93 平方米），比国标宽松三倍，直接照搬会少扣面积、多订材料。

### 平屋面没有山墙，那多出来的面积算哪儿？

算女儿墙。国内住宅以平屋面为主，女儿墙高度常见 1.2 到 1.5 米（临空处防护高度另按规范控制），内外两侧和压顶都要做饰面，是最容易漏算的部位。反过来，坡屋面的别墅和顶层退台才需要算山墙三角面积，公式和工具一致：`面积 = 0.5 x 底宽 x 高 x 个数`。

### 外墙涂料要买多少桶？

先按净面积加损耗得到施工面积，再乘每平方米用量得到重量，最后按包装规格（常见 20 千克或 25 千克一桶）向上取整。底涂、中涂（真石漆）、面涂要分别计算，不同工序用量差很多。基层平整度差、吸水率高时用量会明显上升，抹灰质量决定涂料实际消耗。

### 工具的收边条、起始条数量能用吗？

不能直接用。起始条、J 型槽、阴阳角柱是乙烯基和纤维水泥挂板系统的专有配件，国内涂料和面砖做法里没有对应物；对应的是分格缝、滴水线、窗台披水和阴阳角护角条，按延长米计量。工具算出的延长英尺可以除以 3.281 换成米，用来估算国内的收边线条长度，但子目名称和构造要整套改用国标图集和当地通用做法。
