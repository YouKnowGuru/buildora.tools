## 雪荷载计算器：ASCE 7-22 屋面雪荷载与国标对照

> **重要提示：** 本计算器实现的是美国 **ASCE/SEI 7-22 第 7 章**和 IBC §1608 的屋面雪荷载条文，用于初步估算和教学分析。它**不是**按中国《建筑结构荷载规范》GB 50009-2012 编写的，两套体系的系数定义、折减方式和荷载组合都不一样。国内工程的雪荷载必须按现行国标、当地气象参数和有资质的设计单位出具的计算书取值。

---

## 屋面雪荷载为什么要单独算

屋面积雪是屋盖体系（檩条、屋架、网架、屋面板）在冬季必须承受的竖向重力荷载。取值偏小会导致挠度过大、吊顶开裂，极端情况下屋盖整体垮塌。

新雪的密度大约 80 到 200 千克每立方米（5 到 12 磅每立方英尺），含水的密实雪和雨雪冻结后可达 400 到 900 千克每立方米（25 到 56 磅每立方英尺）。也就是说，同样 30 厘米（12 英寸）的积雪，一场干雪只有 0.2 kN/m² 上下，而一场雨夹雪可能超过 1.5 kN/m²，几小时内翻好几倍。2008 年初南方大范围雨雪冰冻期间，大批轻钢屋盖厂房和大棚正是这样压塌的。

```
雪深换算  雪荷载(kN/m2) = 雪深(m) x 雪密度(kg/m3) x 0.00981
例        0.30 m x 150 kg/m3 x 0.00981 = 0.44 kN/m2 (约 9.2 psf)
单位      1 kN/m2 = 1 kPa = 20.885 psf ; psf x 0.04788 = kN/m2
```

## 两套体系的核心公式

```
ASCE 7-22
  平屋面雪荷载  pf = 0.7 x Ce x Ct x Is x pg
  坡屋面雪荷载  ps = Cs x pf
  最小值控制    取 max(ps, pm)
  漂移堆雪      hd = 0.43 x lu^(1/3) x (pg+10)^(1/4) - 1.5

GB 50009-2012
  屋面雪荷载标准值  sk = μr x s0
  s0 = 基本雪压（50 年重现期，附录 E 查表）
  μr = 屋面积雪分布系数（表 7.2.1）
```

差别一眼就能看出来：ASCE 把地面雪压先乘 0.7 折到屋面，再用暴露系数 Ce、温度系数 Ct、重要性系数 Is 三个乘子调整；国标只有一个 μr，重要性通过结构重要性系数和设计使用年限在荷载组合层面体现，不进雪荷载本身。所以把工具输出的 pf 当成 sk 用是错的——量纲对得上，物理含义不同。

## 中国的基本雪压量级

基本雪压 s0 取 50 年重现期，从 GB 50009-2012 附录 E 的全国分布图和城市参数表里查，不能估。下表只给量级：

| 地区 | 基本雪压 s0（50 年重现期） | 换算 psf |
|---|---|---|
| 华南沿海（广州、海口一带） | 0 到 0.15 kN/m²，多数不控制设计 | 0 到 3 |
| 长江中下游（上海、南京、武汉） | 0.20 到 0.65 kN/m² | 4 到 14 |
| 华北平原（北京、天津、济南） | 0.25 到 0.45 kN/m² | 5 到 9 |
| 东北（沈阳、长春、哈尔滨） | 0.35 到 0.70 kN/m² | 7 到 15 |
| 新疆北部（乌鲁木齐、阿勒泰） | 0.80 kN/m² 以上，局部远高 | 17 以上 |
| 西南高原 | 0.10 到 0.30 kN/m²，垂直差异极大 | 2 到 6 |

北京约 0.40 kN/m²、上海约 0.20 kN/m²，以附录 E 为准。对照工具里美国常见的 20 到 50 psf（0.96 到 2.39 kN/m²），国内绝大多数城市的雪压要低一个量级，这是气候差异，不是规范宽松。

**两条国标条文务必记住：** 第一，对雪荷载敏感的结构——大跨屋盖、轻质屋面、膜结构、悬挑雨棚——应采用 100 年重现期的雪压，不能用 50 年值。第二，屋面均布活荷载不与雪荷载同时组合，取两者较大值；这一点和美国按荷载组合叠加的做法处理方式不同。

## 坡度折减：μr 与 Cs 的差别

| 双坡屋面坡度 | GB 50009 的 μr（趋势值，须查表核对） | ASCE 7 的 Cs（非光滑面、暖屋面） |
|---|---|---|
| 不大于 25° | 1.0 | 1.0（30° 以内均为 1.0） |
| 30° | 约 0.8 | 1.0 |
| 35° | 约 0.6 | 约 0.88 |
| 40° | 约 0.4 | 约 0.75 |
| 45° | 约 0.2 | 约 0.63 |
| 50° 及以上 | 趋近 0 | 到 70° 才降为 0 |

国标的坡度折减比 ASCE 快得多。反过来，国标对高低跨屋面、天沟、拱形屋面的**不均匀积雪**给的是图示化的 μr 分布工况（一侧满载、一侧半载等），而 ASCE 用漂移高度 hd 的经验公式算三角形堆雪。两种方法都要算，但算出来的形状和位置不能互相替换。工具输出的 hd、pd、w 只在 ASCE 体系内有效。

## 算例：同一屋面，两套规范

* 屋面水平投影面积 186 平方米（2000 平方英尺），双坡 6:12（约 26.6°），非光滑瓦面，采暖住宅

**按 GB 50009（北京，s0 = 0.40 kN/m²）**

* μr 在 25° 与 30° 之间插值，取约 0.85
* sk = 0.85 x 0.40 = **0.34 kN/m²（7.1 psf）**
* 屋盖总雪荷载 = 0.34 x 186 = **63 kN，约 6.4 吨（14200 磅）**

**按 ASCE 7-22（佛蒙特州，pg = 35 psf）**

* pf = 0.7 x 1.0 x 1.0 x 1.0 x 35 = 24.5 psf
* 26.6° 小于 30°，Cs = 1.0，ps = **24.5 psf（1.17 kN/m²）**
* 总荷载 = **49000 磅，约 22 吨**

同一屋面差 3.4 倍，全部来自气候参数。这也说明为什么国内多层住宅雪荷载几乎从不控制设计——现浇混凝土屋面板的自重就有 3 到 5 kN/m²，0.34 kN/m² 的雪不构成威胁。真正被雪荷载卡住的是轻钢屋盖、网架、采光顶、光伏支架和农业大棚。

## 荷载组合的差异

国内按 GB 50068 和 GB 55001 的现行规定组合：基本组合中永久荷载分项系数取 1.3，可变荷载取 1.5，雪荷载作为可变荷载参与，并按组合值系数考虑。美国 LRFD 用 1.2D + 1.6S 一类的组合，ASD 用 D + S。数值接近但不通用，构件验算必须整套用同一体系，不能一半国标一半美标。

## 常见问题

### 工具算出来的雪荷载能直接用于国内设计吗？

不能。它按 ASCE 7-22 计算，输出的是 pf、ps、pm 和漂移堆雪，与国标的 sk = μr x s0 定义不同，且用的是美国地面雪压地图。可以用它做概念阶段的量级比较，正式设计必须查 GB 50009-2012 附录 E 的基本雪压、按表 7.2.1 取 μr，并对照当地图集和主管部门要求。

### 基本雪压和地面雪压是一回事吗？

不是同一个口径。国标的基本雪压 s0 是地面积雪自重的 50 年重现期值（对雪敏感结构取 100 年），已经作为屋面计算的基准，直接乘 μr。ASCE 的 pg 也是地面值，但要先乘 0.7 折到屋面，再乘三个系数。少乘或多乘这个 0.7 会造成 30% 的偏差。

### 光伏支架和采光顶要按什么重现期算？

按现行国标，属于对雪荷载敏感的结构时应采用 100 年重现期雪压，同时要考虑组件表面光滑导致的滑落堆积和积雪不均匀分布工况。这类构件在南方低雪压地区最容易被忽略，恰恰也是历次雪灾中损坏比例最高的部分。

### 积雪不均匀分布一定要算吗？

要。高低跨屋面的低跨侧、天沟两侧、女儿墙背风侧、拱形屋面的一侧半跨，都会形成局部远高于均匀值的堆雪。国标用 μr 分布图给出这些工况，ASCE 用 hd 公式。只按均匀荷载验算过的轻型屋盖，垮塌往往就发生在这些局部位置。
