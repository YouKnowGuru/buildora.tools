## 面积计算：公式、计量口径与国标差异

面积是所有工程量的起点——铺砖、刷涂料、下料、报价、算房价，全都从面积走。这个工具把长宽尺寸按几何形状换成面积，支持矩形、圆形、三角形、梯形和 L 形组合，并按材料类别给出含损耗的采购量。

**先把口径说清楚。** 工具算的是美制体系里的 square footage，即按房间净尺寸或外墙外皮量出的平面面积，对应美国房产估价的 GLA（毛居住面积），完全没有"公摊"这个概念。国内的建筑面积是另一套规则，由 GB/T 50353《建筑工程建筑面积计算规范》和现行强制性工程建设规范 GB 55031-2022《民用建筑通用规范》约束，涉及结构层高判定、阳台折半、共有面积分摊等一整套条款，工具并不实现这些规则。装修下料、材料采购用它没问题；报建、房产测绘、售房面积必须回到国标和当地测绘要求。

## 各种形状的面积公式

```
矩形/正方形    面积 = 长 x 宽
圆形          面积 = 3.1416 x 半径 x 半径 ; 周长 = 3.1416 x 直径
三角形         面积 = 0.5 x 底 x 高
梯形          面积 = (上底 + 下底) / 2 x 高
L 形/异形      拆成互不重叠的矩形，分块累加
按毫米量取时   平方米 = 长(mm) x 宽(mm) / 1000000
```

### 算例

* 卧室 4.5 米 x 3.6 米 = **16.2 平方米（174 平方英尺）**
* 圆形景观铺装，直径 4.3 米，半径 2.15 米：3.1416 x 2.15 x 2.15 = **14.5 平方米（156 平方英尺）**
* 山墙三角形，底 4.9 米、高 3.0 米：0.5 x 4.9 x 3.0 = **7.35 平方米（79 平方英尺）**
* 喇叭口车道，上口 4.9 米、下口 3.0 米、进深 6.1 米：(4.9 + 3.0) / 2 x 6.1 = **24.1 平方米（259 平方英尺）**

## 国内的四种面积口径，美制只有一种

这是中美差异最大、也最容易谈崩的地方。国内一套房子同时存在几个面积数字：

| 口径 | 含义 | 用在哪 | 美制有无对应 |
|---|---|---|---|
| **建筑面积** | 套内建筑面积 + 分摊的共有建筑面积 | 产权证、售房合同、报建、容积率 | 无。美国不摊公共面积 |
| **套内建筑面积** | 套内使用面积 + 套内墙体面积 + 阳台建筑面积 | 部分城市按此计价、装修合同 | 最接近 GLA |
| **套内使用面积** | 墙内地面净面积 | 家具排布、地面材料下料 | 接近 usable area |
| **公摊面积** | 电梯厅、楼梯间、设备间、外墙一半等分摊部分 | 只出现在建筑面积里 | 无 |

```
建筑面积   = 套内建筑面积 + 公摊面积
得房率     = 套内建筑面积 / 建筑面积
公摊系数   = 公摊面积 / 套内建筑面积
```

得房率的常见区间：多层住宅 85% 到 88%，小高层 80% 到 85%，高层塔楼 75% 到 80%，带大堂的超高层还会更低。也就是说，一套建筑面积 100 平方米（1076 平方英尺）的高层住宅，套内往往只有 76 到 80 平方米。美国房源挂牌写的面积没有这一层折减，直接拿两国数字比大小会得出错误结论。

**几条常被问到的国标规则：** 结构层高不小于 2.20 米的部位计全面积，小于 2.20 米计一半；阳台按现行规范判定是否折半，主体结构内与主体结构外的处理方式不同；飘窗、设备平台、坡屋顶下净高不足的空间各有专门条款。这些判定逐条写在 GB/T 50353 和 GB 55031-2022 里，且两者存在差异，实际项目务必以现行有效版本、当地规划审批口径和房产测绘机构的要求为准。近年也有部分城市推行按套内建筑面积计价，签合同前看清写的是哪一个面积。

## 损耗率：买多少才够

按实测面积精确采购一定会缺料。切割、错缝排版、门垛收口、拼花对花、运输破损都要吃掉一部分。

| 材料与排版方式 | 建议损耗率 | 主要损耗来源 |
|---|---|---|
| 实木复合/强化地板，直铺 | 5% 到 10% | 端头切割、错缝、色差挑板 |
| 人字拼、斜铺（45 度） | 15% 到 20% | 沿墙全周 45 度切角 |
| 陶瓷/瓷砖，通铺 | 10% 到 12% | 湿切、阴阳角收口、运输破损 |
| 石塑地板 LVT/SPC | 7% 到 10% | 锁扣端头、门口过渡 |
| 地毯（卷材） | 10% 到 15% | 卷宽不匹配、绒向一致 |
| 草坪卷/草皮 | 5% 到 10% | 曲线花池、边缘修剪 |
| 纸面石膏板 | 10% 到 12% | 门窗洞口、接缝排版 |

```
含损耗面积 = 实测面积 x (1 + 损耗率)
需购箱数   = 向上取整(含损耗面积 / 每箱覆盖面积)
```

举例：14.5 平方米的圆形铺装，加 10% 损耗为 15.95 平方米；每箱覆盖 1.86 平方米，则 15.95 / 1.86 = 8.6，取 **9 箱**，实到 16.74 平方米，多出的留作后期修补备用。国内瓷砖通常按片和箱订货，同一批号（窑号、色号）留够备用砖，后期补货很难对上色。

## 单位换算

| 换算 | 公式 | 示例 |
|---|---|---|
| 平方米 → 平方英尺 | x 10.7639 | 100 平方米 = 1076.4 平方英尺 |
| 平方英尺 → 平方米 | x 0.092903 | 1000 平方英尺 = 92.9 平方米 |
| 平方米 → 亩 | / 666.67 | 6666.7 平方米 = 10 亩 |
| 公顷 → 亩 | x 15 | 1 公顷 = 15 亩 = 10000 平方米 |
| 亩 → 英亩 | x 0.1647 | 10 亩 = 1.65 英亩 |
| 平方厘米 → 平方米 | / 10000 | 20000 平方厘米 = 2 平方米 |

场地和用地指标国内用亩和公顷，工具输出的 acre（英亩）要换算：1 英亩 = 4046.86 平方米 = 6.07 亩。

## 常见问题

### 建筑面积 100 平方米，套内到底有多少？

看结构和梯户比。高层住宅得房率多在 75% 到 80%，套内约 75 到 80 平方米（807 到 861 平方英尺）；多层住宅可到 85 平方米以上。装修预算按套内算，物业费和契税一般按建筑面积算，两个数字都要问清。

### 阳台算不算建筑面积？

算，但可能只算一半。是否折半取决于阳台是在主体结构内还是主体结构外，判定条款写在现行建筑面积计算规范里，且不同版本规定有差异。这一条直接影响产权面积和房价，不要凭经验判断，让设计或测绘单位按现行有效版本出具面积表。

### 工具算出来的面积能报建或办产权吗？

不能。工具只做几何面积，不含结构层高判定、阳台折半、公摊分摊、坡屋顶净高等国标条款，也不区分建筑面积与套内面积。它适合装修下料和材料采购量估算。报建、预售、办证的面积必须由有资质的测绘机构按国标出具。

### 一亩地能盖多大房子？

一亩是 666.67 平方米（7176 平方英尺）。能盖多少取决于容积率和建筑密度，两个指标由地块规划条件给定：容积率 1.5 的一亩地，总建筑面积上限约 1000 平方米。这套指标体系在美国由分区法规的 FAR 承担，数值与口径都不通用。
