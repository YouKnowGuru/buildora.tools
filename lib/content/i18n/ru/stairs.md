## Калькулятор лестницы: подъёмы, проступь, косоур и уклон

Инструмент считает число подъёмов, точную высоту подступенка, глубину проступи, заложение марша, длину косоура, уклон и длину поручня по одному исходному размеру — высоте между чистыми полами этажей.

**О калибровке.** Предельные размеры проверяются по американским кодам: **IRC §R311.7** для жилых домов, **IBC §1011** для общественных зданий, **OSHA 1910.25** для промышленных лестниц. Расчёт ведётся в дюймах, косоур подбирается из доски 2x12, ограждение — по IRC §R312. Российские **СП 1.13130.2020** и **СП 55.13330.2016** инструмент не проверяет: геометрия универсальна, а предельные значения и сортамент пиломатериала у нас другие.

---

## Термины

| Термин | Что это |
|---|---|
| Высота подъёма | расстояние между чистыми полами этажей |
| Подступенок | вертикальная часть ступени, её высота |
| Проступь | горизонтальная часть ступени, её глубина |
| Свес | нависание проступи над подступенком, обычно 20–30 мм |
| Косоур | несущая балка с зубчатым верхом, ступени лежат сверху |
| Тетива | несущая балка с пазами, ступени вставлены в боковину |
| Заложение | горизонтальная проекция всего марша |
| Забежная ступень | ступень с переменной глубиной на повороте |

---

## Порядок расчёта

```
1. число подъёмов = высота этажа / целевая высота, округлить
2. высота ступени = высота этажа / число подъёмов
3. число проступей = число подъёмов - 1
4. заложение      = число проступей x глубина проступи
5. длина косоура  = корень(высота^2 + заложение^2)
6. уклон          = арктангенс(высота ступени / проступь)
7. поручень       = длина косоура + 300 мм на загибы
```

Пример для типовой высоты этажа **2800 мм (110 дюймов)**:

* подъёмов 2800 / 175 = **16**, высота ступени ровно 175 мм (6,9 дюйма);
* проступей 16 - 1 = **15**, глубина проступи 280 мм (11 дюймов);
* заложение 15 x 280 = **4200 мм (13,8 фута)**;
* косоур — корень из (2800² + 4200²) = **5048 мм (16,6 фута)**;
* уклон — арктангенс (175 / 280) = **32°**;
* проверка удобства: 2 x 175 + 280 = **630 мм**, попадает в норму.

Все подъёмы в марше должны быть одинаковыми: допуск IRC — 9,5 мм (3/8 дюйма) на марш, российская практика столь же строга.

## Предельные размеры: США и Россия

| Норматив | Максимум подступенка | Минимум проступи | Область |
|---|---|---|---|
| IRC §R311.7 | 197 мм (7,75 дюйма) | 254 мм (10 дюймов) | жилые дома США |
| IBC §1011.5 | 178 мм (7 дюймов) | 279 мм (11 дюймов) | общественные здания США |
| OSHA 1910.25 | 241 мм (9,5 дюйма) | 241 мм (9,5 дюйма) | промышленные лестницы |
| СП 1.13130.2020 | 220 мм (8,7 дюйма) | 250 мм (9,8 дюйма) | пути эвакуации |
| Комфортная практика РФ | 150–180 мм (5,9–7,1 дюйма) | 280–300 мм (11–11,8 дюйма) | жилые дома |

Американский код разрешает более крутой марш: 197 на 254 мм — это 38°, а комфортная российская пара 175 на 280 даёт 32°. Взяв значения из калькулятора без правки, вы получите лестницу, законную в США и неудобную по нашим привычкам.

## Чем российская практика отличается

**Три формулы удобства вместо одной.** Кроме правила Блонделя, у нас проверяют сразу три условия: **2a + b = 600–640 мм**, **a + b = 450 мм** и **b - a = 120 мм**, где a — подступенок, b — проступь. Пара 175 на 280 проходит все три. Американская запись (2R + T = 610–635 мм) — только первая из них.

**Косоур и тетива — разные конструкции.** Американская модель предполагает пропиленный косоур из доски 2x12 (фактически 38 x 286 мм). В российском сортаменте такой доски нет: берут **доску 50 x 250 или 50 x 300 мм**, либо ЛВЛ-брус для длинных пролётов. Условие остаётся тем же — остаток древесины под вырезом не меньше 90 мм (3,5 дюйма).

**Ограждения нормируются иначе.** Высота ограждения по российским правилам — **не менее 900 мм**, а в зданиях с пребыванием детей **1200 мм** с вертикальными элементами и просветом **не более 100 мм**. Стальные ограждения делают по **ГОСТ 25772-83**. Просвет почти совпадает с американским шаром 102 мм.

**Высота прохода задаётся в метрах.** IRC требует 2032 мм (80 дюймов) от свеса ступени до перекрытия, российская норма — **не менее 2000 мм** в чистоте. Разница символическая, но проём проверяют по фактическому пирогу пола.

## Частые вопросы

### Сколько ступеней нужно при высоте этажа 2800 мм?

Шестнадцать подъёмов по 175 мм и пятнадцать проступей по 280 мм. Заложение выйдет 4200 мм — под такой марш нужен проём длиной около 3,3 м, иначе придётся уходить на площадку с поворотом или на забежные ступени.

### Какая высота ступени считается удобной?

150–180 мм при проступи 280–300 мм. Всё, что выше 190 мм, воспринимается как крутая лестница: подъём требует больше усилия, а спуск становится опасным.

### Из чего делать косоур вместо доски 2x12?

Доска 50 x 250 мм для маршей до 3 м заложения и 50 x 300 мм либо ЛВЛ-брус для более длинных. Число косоуров — по ширине марша: при 900 мм ставят три, при 1200 мм четыре с шагом около 400 мм.

### Как считать забежные ступени?

Глубину измеряют по линии движения — обычно в 300–400 мм от внутреннего края марша. По этой линии проступь должна оставаться не меньше расчётной, а у узкого края допускается сужение примерно до 100 мм.

### Нужно ли ограждение при трёх ступенях?

По IRC поручень обязателен от четырёх подъёмов. В российской практике на наружных крылечках ограждение ставят при перепаде более 450 мм независимо от числа ступеней. Ориентируйтесь на перепад высоты, а не на счёт ступеней.
